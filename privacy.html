プライバシーポリシー

「KPIシート連携」（以下「本ツール」）における情報の取り扱いについて定めます。

1. 取得する情報

チャンネル所有者が許可した範囲で、YouTube Data API および YouTube Analytics API を通じて、チャンネルと動画の統計情報（視聴回数、登録者数、視聴時間など）を読み取ります。視聴者個人を特定する情報は取得しません。

2. 利用目的

取得した情報は、チャンネル運用のための社内資料（KPIシート、週報、分析資料、企画資料など）の作成と、チャンネル所有者への報告にのみ使用します。

3. 保管と共有

接続に必要な認証情報は運営者の端末内でのみ保管し、第三者に提供しません。取得した統計情報は、チャンネル所有者と運用チームの間でのみ共有します。

4. 許可の取り消し

チャンネル所有者は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも許可を取り消せます。取り消し後は情報を取得しません。

5. Google API の利用について

本ツールによる Google API から受け取った情報の利用は、Limited Use の要件を含む Google API Services User Data Policy に従います。本ツールは YouTube API Services を利用しており、YouTube 利用規約（https://www.youtube.com/t/terms）および Google プライバシーポリシー（https://policies.google.com/privacy）が適用されます。
